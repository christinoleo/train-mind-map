# The planar rule has no exceptions for edges

Edges can never cross each other, pass through nodes or cross water. No bridges, tunnels or research unlock this. The game brief proposed scarce edge bridges as a relief valve. The designer rejected that: the spatial tension is the core of factory building, and the rail layer is the only way to scale beyond the local plane. Do not "fix" frustration by adding edge crossings; improve moving nodes and train access instead.
