# Decision Log — train-mind-map brief

## 2026-09-24 — Session 1 (Create)

- **Initial idea captured (from user):** Factorio-like factory builder, simplified wherever simplification does not cost fun. The factory is built as a node graph ("mind map", visually like Godot's visual-script / node editor). Target: mobile, played in a web browser; must be lightweight yet mechanically deep.
- **Map:** 2D map with resource deposits. Player places an extractor node that produces a resource every X seconds, with 1+ output connectors on the right (only 1 before researching tech).
- **Production chain:** extractors connect to furnace/factory nodes; same recipe chain as Factorio.
- **Hard rule (tentative):** edges must never cross. Open: a later research might allow crossings (needs playtesting).
- **Edges:** have max throughput; items animate along the edge, colored by item type; multiple item types on one edge show different colors/icons.
- **Trains (core fun, undesigned):** move items far, fast, in bundles; the logistics puzzle is doing this without crossing wires. User explicitly asked for ideas.
- **Genre positioning (user):** "It has puzzle elements, but it is much more of an idle game." Idle is the primary genre, and puzzle is secondary. This aligns with the research finding that browser portals favour idle and incremental factory games. Open: how the puzzle layer (planarity, layout) coexists with the idle loop.
- **Genre clarified (user):** "It is a factory builder, not a puzzler." The feel is clicker/idle (the user sees clicker and idle as closely related). This supersedes the earlier "puzzle elements" framing: planarity is a building constraint, not the game's identity as a puzzle game.
- **Click role (user):** production starts manual (tap the resource to produce, like hand-mining in Factorio), and automation gradually removes the need to click until the game becomes idle.
- **Goals (user):** "A bit of everything, like Factorio": a final goal plus a map that expands as research unlocks it. Prestige (reset onto a new map with a bonus) is a stretch goal.
